# HYROX Seoul 2026 시간표

HYROX Seoul 2026(2026.11.13–15) 출발 시간과 시상 스케줄을 이름으로 찾아 한눈에 보는 개인 제작 웹페이지입니다.

- 이름이나 배번으로 검색해 내 목록에 추가하면 날짜별, 디비전별로 정리됩니다.
- 디비전별 출발 시간대와 시상식 일정을 함께 보여줍니다.
- 목록은 각자 브라우저(localStorage)에만 저장됩니다.

## 구성

`index.html` 한 파일로 동작하는 정적 페이지입니다. 빌드 과정이 없고, 선수 데이터는 파일 안에 포함되어 있습니다.

## 데이터

- 출처: [startlist.hyrox.com](https://startlist.hyrox.com/) 2026 Seoul 시작 리스트 (2026-11-10 수집)
- 시상 스케줄과 출발 시간대: 대회 공식 타임테이블
- 웨이브 변경이나 추가 등록이 있으면 데이터를 다시 수집해 `index.html`을 갱신해야 합니다.

HYROX 공식 페이지가 아닙니다.
